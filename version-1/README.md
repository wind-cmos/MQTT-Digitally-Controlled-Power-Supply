# MPPT DC-DC 电源模块

本仓库用于整理基于 TI LM5176 的同步四开关 Buck-Boost DC-DC 电源模块设计资料。项目目标是在宽输入电压范围内实现稳定、可调的输出电压，并保留原理图、PCB 导出文件和调试波形截图，便于后续复盘、迭代与测试记录归档。

## 设计概览

- 主控芯片：TI LM5176PWPR，同步四开关 Buck-Boost 控制器，HTSSOP-28 封装。
- 功率拓扑：四开关同步升降压结构，支持 Buck、Boost、Buck-Boost 模式平滑切换。
- MOSFET：4 个 N 沟道 MOSFET，型号为 APO077N01G。
- 储能电感：L2，约 4.7 uH。
- 控制方式：峰值电流模式控制，配合电流采样与环路补偿实现稳定输出。

## 主要设计指标

| 项目 | 参数 |
| --- | --- |
| 输入电压范围 | 约 4.2 V ~ 55 V，器件最大绝对额定值 60 V |
| 输出电压范围 | 约 0.8 V ~ 55 V |
| 输出电流 | 最大约 5 A，实际能力取决于散热、PCB 布局和器件选型 |
| 开关频率 | 约 106.1 kHz，通过 RT 引脚外接电阻设定 |
| 软启动时间 | 约 16 ms，通过 SS 引脚外接电容设定 |

## 拓扑与工作模式

电路采用四开关同步 Buck-Boost 拓扑，由 Buck 半桥、Boost 半桥和单电感组成。

- Q4/Q5：Buck 侧上、下管，组成降压半桥。
- Q2/Q3：Boost 侧上、下管，组成升压半桥。
- L2：储能电感，用于能量传递与连续电流控制。

不同输入、输出电压关系下，控制器会自动切换工作模式：

| 模式 | 条件 | 开关动作 |
| --- | --- | --- |
| Buck 降压模式 | VIN 明显高于 VOUT | Buck 侧进行高频 PWM，Boost 侧保持相应导通/关断状态 |
| Boost 升压模式 | VIN 明显低于 VOUT | Boost 侧进行高频 PWM，Buck 侧保持相应导通/关断状态 |
| Buck-Boost 升降压模式 | VIN 接近 VOUT | 四个开关协同 PWM，实现模式间平滑过渡 |

## 关键外围电路

### 输入级与 UVLO

EN/UVLO 引脚通过外部分压电阻设置启动阈值。输入端并联大容量电解电容和多颗陶瓷电容，用于降低输入纹波并改善瞬态响应。

### 输出电压设定

输出电压由 FB 引脚分压网络设定，FB 基准电压约为 0.8 V。

```text
VOUT = 0.8 V x (1 + RH / RL)
```

### 电流检测

ISNS(+)/ISNS(-) 引脚用于检测电感电流，实现逐周期电流限制。设计中包含毫欧级采样电阻和 RC 滤波网络，用于提升检测稳定性并抑制开关噪声。

### 软启动与环路补偿

SS 引脚外接电容设置软启动时间。COMP 引脚外接 RC 补偿网络，用于保证系统环路稳定性。SLOPE 引脚用于斜率补偿设置。

### 栅极驱动与自举

LM5176 内部集成栅极驱动能力，外部通过自举电容和二极管为高边驱动供电。Buck 侧和 Boost 侧均配置独立自举电容。

## 保护功能

LM5176 提供多种保护机制，适合宽输入 DC-DC 电源场景。

| 保护功能 | 实现方式 |
| --- | --- |
| 逐周期电流限制 | 监测 ISNS 引脚电压 |
| 输入欠压锁定 UVLO | 通过 EN/UVLO 引脚设定启动与关断阈值 |
| 输出过压保护 OVP | 检测 VOUT，异常时关断开关动作 |
| 输出短路保护 | 短路或过载时进入保护状态 |
| 热关断 | 芯片过温时自动关断 |
| Hiccup 打嗝模式 | 持续过载时周期性重启，降低器件应力 |
| Dither 扩频 | 可用于降低 EMI 峰值 |

## 测试接口

- J3：VIN 输入测试端，KF7.62-2P 绿色端子，输入范围约 4.2 V ~ 40 V。
- J4：7 V 光耦测试接口。
- J5：VOUT 输出测试端，KF7.62-2P 绿色端子。
- R25/R13：输出电压分压测试点。
