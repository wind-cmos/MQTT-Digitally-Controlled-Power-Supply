# MQTT Digitally Controlled Power Supply

模块化数控电源硬件项目，使用 Altium Designer 设计。项目由 MMT 电源模块、MCU 控制与接口板、BACK 背板组成，分别承担电能转换与输出调节、系统控制与外设接口、模块互连与输出连接功能。

## 模块功能与当前进度

截至 2026-10-28，项目进度由项目作者确认如下：

| 模块 | 主要功能 / 设计内容 | 当前进度 | 工程入口 |
| --- | --- | --- | --- |
| [MMT](MMT/) | 开关电源变换、辅助供电、恒流 / 恒压控制、输出泄放、DAC / ADC 设置与采样、状态指示及总线隔离 | **已完成功能调试** | [MMT.PrjPcb](MMT/MMT.PrjPcb) |
| [MCU](MCU/) | 系统控制与外设接口板，包含网络与通信、显示与触摸、存储、启动及多路供电等设计内容 | **正在设计** | [MCU.PrjPcb](MCU/MCU.PrjPcb) |
| [BACK](BACK/) | 背板与模块互连，包含 DIB 连接接口和电源输出耦合 / 连接电路 | **正在设计** | [BACK.PrjPcb](BACK/BACK.PrjPcb) |

MCU、BACK 的功能说明描述当前设计范围，不代表这些接口或整机功能已经调试完成。本次同步的是硬件工程与现有文档，不包含完整的 MCU / MQTT 应用固件。

## 初版设计记录

全工作输入电压：16V ～ 20V，标称值 18V

输出电压：0V ～ 35V

30V 输出时，输出电压纹波 < 250mV

跟踪功能：30V 降至 5V 的响应时间为 2000µs

同步频率控制范围：400kHz ～ 500kHz

峰值输出功率：300W（第一版）

波峰因数（有效值与峰值之比）：4（对应 75W 持续功率）

峰值功率维持时间：200ms

标称效率：满载、标称输入电压下 > 93%

采用 DAC控制输出电压

最高环境工作温度：85°C

具备短路保护

具备限流功能
