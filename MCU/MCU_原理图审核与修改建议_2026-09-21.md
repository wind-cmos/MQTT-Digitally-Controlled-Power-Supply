### 1.1 MP1584 使能阈值与主电源

R36=30 kΩ、R37=5 kΩ，在 12 V 下 EN 标称约 1.714 V。如果两者均为图中标注的 5% 精度，最不利组合约 1.572 V，低于器件使能上升阈值的 1.65 V 最大值。因此即使修复 `VIN` 网络，还要按最低输入电压、阻值容差和目标欠压关断点重算。

当前反馈 210 kΩ/40.2 kΩ 对应约 4.98 V，标称分压本身合理；不把它误判为反馈接反。补偿参数、负载阶跃、输入浪涌、二极管和电感余量需要独立验证。依据：[MPS MP1584 数据手册](https://www.monolithicpower.com/en/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MP1584EN-LF-Z/document_id/204/)。

AMS1117 的总负载预算尚未完成。F769、C3、SDRAM、PHY、SD 卡同时工作时，应统计峰值电流；例如 5 V 降至 3.3 V、0.5 A 时，仅 LDO 损耗就为 0.85 W。是否换同步 Buck，应根据实际电流和 PCB 温升决定，不能只看“额定 1 A”。

### 1.2 CAN 的正确电源与接线

| U19 管脚 | 连接 |
|---|---|
| 1 VCC1 | 主控 `+3V3` |
| 2 TXD | STM32 CAN_TX，复位默认保持隐性电平，可加约 10 kΩ 上拉 |
| 3 RXD | STM32 CAN_RX |
| 4 GND1 | 主控 `GND` |
| 5 CANL | 总线 CANL |
| 6 CANH | 总线 CANH |
| 7 GND2 | 独立 `GND_CAN_ISO` |
| 8 VCC2 | 独立 `+5V_CAN_ISO` |

CA-IS1044S 隔离信号，但不产生隔离电源。总线侧推荐供电范围为 4.5-5.5 V，不能直接使用主控的 3.3 V。可由本机辅助电源经隔离 DC/DC 产生，或由接口外部提供符合要求的隔离电源；本机自带通常更便于独立使用。每个电源域各放就近 100 nF 去耦及适当储能电容，不能跨隔离栅随意共地。[川土 CA-IS1044S 数据手册，第 4-5 页](https://e.chipanalog.com/Public/Uploads/uploadfile/files/20240611/CAIS1044SdatasheetVersion1.05en.pdf)

还需明确 CAN 连接器、总线参考地和浪涌/ESD 保护。R58=120 Ω 应做成可选装/跳帽，只在物理总线两端启用。F769 的片上 CAN 按经典 CAN 配置；收发器的速率能力不等于 MCU 支持 CAN FD。

### 1.3 双升级 Flash

U16、U17 每片 W25Q32 是 32 Mbit，即 4 MiB；当前是两片合计 8 MiB，不是一片内已经完成 A/B 分区。

- 第 6 脚 CLK 共用，5 脚 DI/MOSI 共用，2 脚 DO/MISO 共用。
- U16.1 改为 `FLASH_A_CS`，U17.1 改为 `FLASH_B_CS`，各加约 10 kΩ 上拉。
- 用普通 SPI 存升级镜像即可；现有 WP#/HOLD# 上拉可用于此模式。
- U20 是 ESP32-C3 启动 Flash，不并到 STM32 升级 Flash 总线上。
- 单片 4 MiB 对一个不超过 F769 内部 Flash 容量的镜像有余量，但仍需明确镜像头、签名和元数据空间。

硬件有两片存储不等于已经具备安全回滚。内部 Bootloader 要保留并保护；擦内部 App 前必须确认至少一份可恢复镜像有效。升级状态使用冗余记录和原子提交，完成新版本自检后再确认版本，测试下载、擦除、写入、首次启动等阶段断电。远程升级应验证签名，CRC 只负责检测随机损坏。AT24C256 可存参数/状态，不是替代内部启动代码的执行存储器。

### 1.4 背光正确拓扑

```text
+5V -> L1 -> SW节点 -> D3 -> VLED+ -> 屏幕LED串 -> VLED- -> R20 -> GND
            |                                               |
          U12.SW                                          U12.FB

D3阴极/VLED+ -> 输出电容 -> GND
```

历史说明：上述升压拓扑修复仅适用于需要升压的屏，不适用于最新 CL35BC1070-40A。此前 H043A22 的 LEDK=8、LEDA=10、80mA/2.55Ω 建议全部不再采用。CL35 新屏 LEDA=33、LEDK=34/35/36，约 3.1V、典型总电流 120mA；应移除原 5V 升压支路并按新复核报告设计低压限流/PWM。反馈原理参考：[TI TPS61169](https://www.ti.com/lit/ds/symlink/tps61169.pdf)。

## 四、为什么不能只把新功能接到空脚

本节及其 A/B 表为保留原 RGB-LTDC 电路的历史条件方案。采用最新 CL35BC1070-40A 时，应按 SPI 或 FMC 显示接口重新分配，不按本节直接改线；也不沿用此前 H043A22 的屏幕假设。

当前 131 个 GPIO 位置中，只有 PA10、PI8 没有接网络；断开 SDRAM 的 NC36 后还可以释放 PG2。新增 UART、CAN、SPI Flash 及控制脚超过这些空脚，而且 UART/CAN/SPI 必须满足特定复用映射。

因此需要接口迁移。下列两案均保留 SDRAM、RGB565 LCD、1-bit SD、I2C EEPROM/触摸、UART4 外部串口、SWD 和 SWO。

| 条件 | 方案 A | 方案 B |
|---|---|---|
| 外部 SPI2/SPI4/SPI5 | 三路都保留 | 只保留 SPI2；SPI4 改本地 Flash，外部 SPI5 取消 |
| Ethernet | MII 改 RMII，增加独立 50 MHz 有源时钟 | 保留 MII 和现有 25 MHz 时钟路径 |
| USB | 仅设备模式，释放 OC/PSO GPIO | 不占用原 OC/PSO，但仍须修正 USB 角色电路 |
| MCU-C3 | USART1 | UART7 |
| CAN | CAN1 | CAN3 |
| 固件 Flash | SPI6 + 两个软件片选 | SPI4 + 两个软件片选 |
| 分配后 GPIO 余量 | 0；若 LCD 无 RESET 可再释放该脚 | PI8；若 LCD 无 RESET 可再释放 PG2 |

三路外部 SPI 确实都要保留、USB 只接电脑时，采用 A。仅需要一路外部 SPI 且想保留 MII 时，B 改动更少。三路 SPI、MII、USB Host 和所有新增控制同时保留时，这两案均不适用，应再考虑 GPIO 扩展器、复位控制电路或更大封装；不能直接占用已有引脚。

## 五、GPIO 初值、EXTI 和启动阶段要求

- Flash 两个 CS：外部上拉，初始化先输出高，再启用 SPI；下载/复位期间不得同时选中两片。
- ESP_EN、ESP_BOOT_N：按开漏下拉控制，释放后由上拉决定高电平；预留人工下载方式，以防 STM32 程序本身无法启动。
- PHY_RESET_N：外部上拉，初始化阶段拉低，在其供电和参考时钟稳定后按手册时序释放。开漏控制不等于省略完整上电复位条件。
- LCD_DISP、LCD_RESET：根据实际有效极性添加上下拉，电源/时钟未稳定时禁显并保持复位。
- 功率控制 PWR_DIRECT/PWR_SSTART/OE_SYNC：启动、Bootloader 擦写、MCU 复位和看门狗期间都必须保持硬件安全状态。具体高低取决于功率板逻辑；本次不在缺少整机逻辑时擅自指定。
- SWD 保留 PA13/PA14，SWO 保留 PB3；PA15/PB4 的功能使用不能与完整 JTAG 同时启用。
- UART TX/RX 使用 3.3 V 逻辑，STM32 与 C3 在非隔离电源域共地。若任一芯片可单独断电，另核对 IO 反灌。
- PA9 使用专用 VBUS 检测时，按 ST 要求保留浮空输入状态，不配置为 USART1_TX 或任意 AF；它并未因 USART1 的使用而自动被占用。

EXTI 同一编号不能同时映射两个 GPIO 端口。建议：

| 输入 | 方案 A | 方案 B |
|---|---|---|
| FAULT | PB2 / EXTI2 | PB2 / EXTI2 |
| SPI2_IRQ | PA8 / EXTI8 | PF8 / EXTI8 |
| SPI4_IRQ | PA3 / EXTI3 | 不再使用 |
| SPI5_IRQ | PA15 / EXTI15 | 不再使用 |
| IRQ_TOUCH | PD7 / EXTI7 | PD7 / EXTI7 |
| USER_SW | PG9 / EXTI9 或轮询 | PG9 / EXTI9 或轮询 |
| ENC_SW | PG2 轮询，避免与 FAULT 的 EXTI2 冲突 | PI4 / EXTI4 或轮询 |
| SD_DETECT | PC3 轮询，避免与 SPI4_IRQ 的 EXTI3 冲突 | PG14 / EXTI14 或轮询 |
| RTC_REF | PB15 可考虑 TIM12_CH2 捕获，不与 SPI5_IRQ 争 EXTI15 | PB15 / EXTI15 或 TIM12_CH2，按用途选择 |

编码器 A/B 保留 PC6/PC7 的 TIM3 编码器接口，背光 PWM 保留 PD12/TIM4_CH1。LTDC 并不是所有引脚都用 AF14；例如 PB0、PB1、PG10、PI11 对应功能为 AF9，完整表中已分别列出。

全部 131 个 GPIO 的当前占用、方案 A/B 和 AF 映射见 [MCU 引脚分配与占用表](D:/桌面/work/project/PCB/AD/数控电源/MCU/MCU_引脚分配与占用表_2026-09-21.md)。引脚依据：[ST 官方封装数据库](https://github.com/STMicroelectronics/STM32_open_pin_data/blob/master/mcu/STM32F769IITx.xml)、[ST 官方 GPIO 复用数据库](https://github.com/STMicroelectronics/STM32_open_pin_data/blob/master/mcu/IP/GPIO-STM32F76x_gpio_v1_0_Modes.xml)。

## 六、修改后的验证清单

1. 在 Altium 更新/编译项目，确认最新六页均被纳入；整理重复位号、显式地名和电源网络。重新生成编译网表核对 H01-H10。
2. 决定 A/B 或其他资源方案，在 CubeMX 选择准确 STM32F769IITx 封装，检查所有 AF、时钟树、DMA 和中断。此报告不是已验证的完整 .ioc。
3. 确认屏幕型号、背光参数、USB 角色、三路外部 SPI 是否必需，以及外部 +3.3 V/+VAUX 的供电方向。
4. PCB 检查所有芯片的电源脚/裸焊盘、去耦回路、SDRAM/RMII 时序、晶体回路、RF 匹配与天线净空，以及 CAN 隔离间距。不要为“防天线效应”取消高速数字区连续参考地，也不要让高速回流跨地分割缝。
5. 样机用限流电源分支路上电，先测 12 V/5 V/3.3 V/隔离 5 V 及复位，再测 SWD、两片 Flash 的独立读写、C3 启动、CAN、SDRAM、背光和网口。
6. 最后测试 Wi-Fi 发射时电源跌落、USB 热插拔/反灌、功率板开关噪声，以及升级断电恢复；验证过程中保持电源输出默认关闭。

本次只输出审核和引脚分配文件，没有修改 CAD。最终连线应以用户确认的接口用途和原生 Altium 编译结果为准。
