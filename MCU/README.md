# MCU 控制与接口板

**当前状态：正在设计（2026-10-28）。**

MCU 模块面向数控电源的系统控制、人机交互和通信扩展。当前原理图文件覆盖的设计内容包括：

- 通信接口：Ethernet PHY、CAN、USB / Type-C，以及 Wi-Fi 与启动相关电路。
- 人机交互与外设：显示屏、触摸、音频及 IO 连接接口。
- 存储接口：DDR4、SDRAM、eMMC、OSPI Flash、EEPROM 和 SD 卡相关设计页。
- 系统基础电路：SoC 与外设供电、3.3 V / 5 V 电源、启动模式、复位监控及按键去抖相关电路。

以上是现有设计文件的内容概述，部分页面可能属于方案迭代或预留设计，并不表示所有接口均已接通、启用或完成调试。主控与接口配置请以当前工程和后续设计更新为准。

## 使用与文档

使用 Altium Designer 打开 `MCU.PrjPcb`。目录同时保留现有 `MCU.PcbDoc`、`MCU.pdf` 以及 Markdown、SVG、PNG 设计说明材料。

带日期的引脚表、方案评估、审核笔记和电源页说明用于保留设计过程，可能涉及旧版主控、旧网络名称或已更名的页面，不能直接作为当前版本的接线或验收依据。PDF 沿用原有导出文件，本次未重新生成。

器件库、封装库、历史记录和缓存不上传。工程引用的库需自行配置；使用 `MCU.OutJob` 输出任务前，请检查输出路径及相关设置是否适合本机环境。
