# D350T1013V1：MIPI、升级 Flash、Wi-Fi、CAN、三组互补 PWM 最终引脚建议

> 2026-09-22；基于当前保存的六张 MCU 原理图。主控 U1 为 STM32F769IIT6（LQFP176），Wi-Fi U18 为 ESP32-C3，屏幕为 D350T1013V1 / ST7701S / FT5316。替代先前 ST7796、8080、RGB 外接总线方案。本文件是改线建议，没有回写 SchDoc/PcbDoc。

结论：能够保留现有模块功能，并加入三组硬件互补 PWM、硬件刹车和驱动使能。代价是迁移五个现有低速 GPIO 功能；SD 卡检测改为轮询。本方案把 131 个可复用 GPIO 全部分配了，六根 DSI 专用信号另计。若只用两组 PWM，可以空出 PI7 和 PB1。

“引脚分配通过”不等于整板可投产：屏幕供电/IO 电平仍需厂商确认，电源元件、PCB、原生 ERC 和整机时钟/软件尚未完成验证。用户已确认保留独立屏幕电源，不能擅自直连主板 3.3V。

完整的现有/最终 131 个 GPIO、AF、旧 RGB 网标、FPC 针脚和源文件哈希，见 [完整引脚表](D:/桌面/work/project/PCB/AD/数控电源/MCU/D350T1013V1_MCU完整引脚表_2026-09-22.md)。下列数字脚号全部是 U1 LQFP176 的物理脚号，不是其他封装。

## 1. FPC1：两数据通道 MIPI DSI

DSI 是 MCU 专用引脚，不需要分配普通 GPIO，也不能通过 GPIO AF 换脚。

| FPC1 物理针号 | 屏端信号 | 最终网名 | U1 专用信号 | U1 物理脚 |
|---:|---|---|---|---:|
| 5 | D0N | DSI_D0_N | DSI_D0N | 102 |
| 6 | D0P | DSI_D0_P | DSI_D0P | 101 |
| 8 | CLKN | DSI_CK_N | DSI_CKN | 105 |
| 9 | CLKP | DSI_CK_P | DSI_CKP | 104 |
| 11 | D1N | DSI_D1_N | DSI_D1N | 108 |
| 12 | D1P | DSI_D1_P | DSI_D1P | 107 |

| FPC1 其他针号 | 最终接法 |
|---|---|
| 1 | LCD_LEDA，接恒流升压背光输出正端；不是 +VDD_LCD |
| 2 | LCD_LEDK，接背光驱动 FB/采样电阻上端；不是直接接地 |
| 3 | +VDD_LCD，独立 LCD 电源 |
| 4、7、10、13-33、35-37、39 | 全部真正连接 GND；符号上写 GND 不代表已经接地 |
| 34 | LCD_RESET_N，接 PG2 / 110，开漏复位 |
| 38 | 接 +VDD_LCD，按厂家 MIPI 接法拉高 |
| 40 | NC，明确不连接 |
| 41、42 | 连接器额外固定/屏蔽焊盘，按连接器机械资料处理；不属于屏幕 40 根信号 |

模式选择的 IM0/IM1 名称在文档不同位置有笔误，但机械图、MIPI 针脚表及参考电路都对应物理 38 拉高、39 接地。按物理针号画图，向供应商确认实际物料版本，不能照符号上下顺序接线。

DSI 电源必须补齐：

- U1.99 VDDDSI 保持接主板 +3V3，邻近放置 100nF 去耦；不要改接屏幕 2.8V 电源。
- U1.100 VCAPDSI 与 U1.106 VDD12DSI 保持相连，在此节点新增 2.2uF 到 GND。当前只有两脚相连，未看到该电容。
- U1.103、109 VSSDSI 保持接 GND。不能把 VCAPDSI 节点接 3.3V，也不能拿它给其他器件供电。

软件采用 SDRAM 帧缓冲 -> 内部 LTDC -> DSI Host -> 屏幕的 Video Mode 链路。删除外部 LTDC GPIO 网络，不代表关闭内部 LTDC。ST7701S 不含显示帧存储器，保留 U9 SDRAM。480×800 RGB565 单帧需 768000 字节，双缓冲需 1536000 字节；实际总线带宽、缓存一致性和时序仍要验证。不要沿用 ST7796 的 FMC 命令/数据地址接口。参考 [ST 数据手册](https://www.st.com/resource/en/datasheet/stm32f769ii.pdf) 的 DSI 供电章节与屏厂 ST7701S 文档。

## 2. FPC2：FT5316 电容触摸和独立电源

| 功能 | MCU 引脚（物理脚） | 最终接法 / 配置 |
|---|---|---|
| I2C1_SCL | PB6（164） | AF4；保持 EEPROM 端不变，经电平转换后到 FPC2.3 / CTP_SCL |
| I2C1_SDA | PB7（165） | AF4；保持 EEPROM 端不变，经电平转换后到 FPC2.2 / CTP_SDA |
| IRQ_TOUCH | PG7（115） | FPC2.5 / CTP_INT_RAW 经单向电平转换到 PG7；EXTI7 |
| CTP_RESET_N | PG6（114） | FPC2.6；开漏输出，上拉到确认后的触摸 IO 电平 |
| LCD_RESET_N | PG2（110） | FPC1.34；开漏输出，上拉到确认后的 LCD RESET IO 电平 |
| PANEL_PWR_EN | PH4（45） | GPIO，控制独立屏/触摸电源使能；硬件下拉，默认关闭 |
| TFT_BRIGHTNESS | PD12（93） | TIM4_CH1 / AF2，保留，接 U12.4 CTRL |

FPC2.1 -> GND，FPC2.4 -> +VDD_CTP。FPC2.7/8 是额外固定焊盘，按连接器资料处理。当前 U13/TSC2007 已删除，不能再把电阻触摸 X/Y 网络接进来；旧 PD7 / IRQ_TOUCH 网标在当前 MCU 快照中也已删除。

### 电源与电平隔离预留

模组规格书电气表写 LCD VDD 2.7-2.9V，针脚表写 2.8-3.3V，IO 又列出 1.8V / 2.8V 两种。不能仅凭其中一处表格定版。

- 保留独立 +VDD_LCD、+VDD_CTP；LCD 电源先按 2.8V 可配置方案设计，3.3V 装配选项须得到屏厂确认。触摸芯片和模组的供电约束应分别核对，不能因 LCD 用 2.8V 就推定触摸 IO 也是 2.8V。
- 预留 +VIO_LCD、+VIO_CTP 参考电平配置点。它们用于复位上拉、触摸总线/INT 转换，不是给模组虚构新增的 FPC 电源针脚。若模组内部分出 1.8V 且未引出，须供应商给出允许的外部接口电平和时序，不能自行猜测。
- LCD_RESET_N、CTP_RESET_N 均为 MCU 开漏输出、关闭内部上拉，外部约 10k 上拉到各自确认后的 IO 电平；不要用主板 3.3V 推挽驱动。复位在屏电源稳定前保持有效，关电前再次拉低。
- 将 FPC2.2/3 上直接连接的 I2C1_SDA/SCL 网标改为 CTP_SDA/SCL，主板 PB6/PB7、R2/R3 和 U10 EEPROM 上的原网名/3.3V 上拉保留。主板与屏端之间加入 TCA9406；不是删掉整个 I2C1 网络。
- TCA9406 的 A 侧接 +VIO_CTP，B 侧接主板 +3V3，A 侧 SDA/SCL 接屏，B 侧接主板。OE 参考 A 侧电压，不要把 3.3V PANEL_PWR_EN 直接接到可能为 1.8V 的 OE；通过电源时序/适当电平转换控制。外部上拉结合芯片内置上拉和总线电容计算，不盲目多组并联。
- FPC2.5 的 INT 使用 SN74LVC1T45：A 接屏端 CTP_INT_RAW，VCCA 接 +VIO_CTP；B 接 IRQ_TOUCH/PG7，VCCB 接主板 3.3V；DIR 按器件要求置高实现 A -> B。若屏 INT 为开漏，屏端上拉到 +VIO_CTP；中断触发方式按模组固件设置。
- C62/C63 若用于触摸去耦，应从当前主板 +3V3 改接 +VDD_CTP 与 GND，并布在 FPC2 附近；LCD 电源另加邻近去耦。电源容量、LDO 稳定性、电容和开关时序按最终模组要求验证。
- 这是电压域转换，不是电气隔离，LCD、CTP 与 MCU 共地；DSI 差分线不经过上述普通逻辑电平转换器。

以上器件接法参考 [TCA9406](https://www.ti.com/lit/ds/symlink/tca9406.pdf) 与 [SN74LVC1T45](https://www.ti.com/lit/ds/symlink/sn74lvc1t45.pdf)。电压装配值没有得到确认前，不应把整板状态标为可投产。

## 3. Bootloader：U16/U17 两片 W25Q32 的 SPI1

内部受保护 Flash 放 Bootloader；U16/U17 用来存放旧/新镜像，不能取代内部启动代码。两片共享 SPI，总线只有 STM32 驱动；ESP32 本地的 U20 不接入这一组网络。

| 保留的 Flash 网名 | MCU 引脚（物理脚） | 配置 | 芯片端 |
|---|---|---|---|
| SPICLK_2 | PG11（154） | SPI1_SCK / AF5 | U16.6、U17.6 |
| SPIQ_2 | PB4（162） | SPI1_MISO / AF5 | U16.2、U17.2 |
| SPID_2 | PD7（151） | SPI1_MOSI / AF5 | U16.5、U17.5 |
| SPICS_2 | PG10（153） | GPIO 输出，默认高 | U16.1 |
| SPICS_3 | PG12（155） | GPIO 输出，默认高 | U17.1 |

必须把 PB4 原有的 SPI2_CSA 改到 PI0，见后面的迁移表。PD7 不再是触摸 IRQ。两片 /CS 各加约 10k 上拉，避免上电时同时选中；每片电源局部去耦。采用标准 1-1-1 SPI 时 WP#/HOLD# 保持合适上拉，不要接地。共享 MISO 必须确保两个片选不同时有效。

Bootloader 从内部 Flash 执行，校验新镜像后写内部执行区；写入过程掉电恢复、镜像合法性/签名、版本/状态双记录、写保护和回滚都由软件实现。外部双镜像不是 MCU 自动硬件 A/B 启动。SWD/SWCLK/SWO、NRST 和 BOOT0 救援机制保留；不额外占用一个“Bootloader 专用 GPIO”。外部 SPI Flash 也不等于 ROM Bootloader 的原生启动介质。

## 4. Wi-Fi：USART6 连接 ESP32-C3

| 最终网名 | STM32 引脚（物理脚） | 模式 | ESP32-C3 端 |
|---|---|---|---|
| U0RXD | PG14（157） | USART6_TX / AF8 | U18.27 U0RXD |
| U0TXD | PG9（152） | USART6_RX / AF8 | U18.28 U0TXD 经现有 R49 后的 U0TXD 网络 |
| ESP_EN | PD3（145） | 开漏：低复位，高阻释放 | U18.7 CHIP_EN；现有 EN 网重命名，保留 R63/C102/SW2 |
| ESP_BOOT_N | PA10（125） | 开漏：低请求下载，高阻正常启动 | U18.15 GPIO9；约 10k 上拉至 3.3V |

保留 USART6 双线全双工，不启用 RTS/CTS，协议层做分包、确认和流控。不要同名 TX 接 TX：表中 U0RXD/U0TXD 是 ESP32 侧的命名。PG14 原 SD_DETECT、PG9 原 USER_SW 都要迁移。

GPIO2、GPIO8、GPIO9 是 C3 启动配置脚，按 [乐鑫原理图检查指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32c3/schematic-checklist.html) 设置确定电平；下载模式需要 GPIO9 低、GPIO8 高，并正确复位。保留 UART/EN/BOOT 测试点。当前 U20 的 IO2/IO3 没有接到 C3 SPIWP/SPIHD，若维持此接法，使用双线 DIO Flash 模式，不能在固件里误配 QIO；要用 QIO 就补齐对应两根线并复核上拉。不要把 STM32 BOOT0 与 ESP_BOOT_N 相连。

## 5. CAN：CAN3 + CA-IS1044S

| 网名 | MCU 引脚（物理脚） | 配置 | U19 端 |
|---|---|---|---|
| CAN_RX | PA8（123） | CAN3_RX / AF11 | U19.3 RXD |
| CAN_TX | PA15（138） | CAN3_TX / AF11 | U19.2 TXD |

PA8 原 SPI2_IRQ、PA15 原 SPI5_IRQ 要迁移。F769 采用经典 CAN 控制器，不因更换收发器就获得 CAN FD。

U19 供电必须修改，参见 [CA-IS1044S 数据手册](https://e.chipanalog.com/Public/Uploads/uploadfile/files/20240611/CAIS1044SdatasheetVersion1.05en.pdf)：

- 1/VCC1 -> 主板 +3V3，4/GND1 -> 主板 GND。
- 8/VCC2 -> +5V_CAN_ISO，7/GND2 -> GND_CAN_ISO；总线侧推荐供电范围为 4.5-5.5V，不能沿用 3.3V。
- 当前 R56 把 VCC2 连到主板 3.3V，R57 把 GND2 连回主板地。移除这些跨隔离边界的导电连接，加入合适的隔离 DC/DC，或使用外部真正隔离的 5V。不是仅改一个网名。
- 两侧各自用 100nF 就近去耦到各自地；CAN 侧再按电源要求配储能电容，TVS 回到 CAN 侧地。PCB 保持隔离带，不跨带铺铜。
- 5/CANL、6/CANH 接总线接口。R58 的 120Ω 终端做可选，仅总线两端装配；不是每块板都必须装。

## 6. 新增三组互补 PWM：统一使用 TIM8

| 相/用途 | 正向输出 | 物理脚 | 互补输出 | 物理脚 | 配置 |
|---|---|---:|---|---:|---|
| U 相 | PI5 / MOTOR_PWM_UH | 174 | PA5 / MOTOR_PWM_UL | 51 | TIM8_CH1 / TIM8_CH1N，AF3 |
| V 相 | PI6 / MOTOR_PWM_VH | 175 | PB0 / MOTOR_PWM_VL | 56 | TIM8_CH2 / TIM8_CH2N，AF3 |
| W 相 | PI7 / MOTOR_PWM_WH | 176 | PB1 / MOTOR_PWM_WL | 57 | TIM8_CH3 / TIM8_CH3N，AF3 |
| 硬件刹车 | PA6 / MOTOR_BKIN | 52 | - | - | TIM8_BKIN，AF3；不是普通 EXTI |
| 功率驱动使能 | PI10 / MOTOR_EN | 12 | - | - | GPIO；硬件默认关闭 |

三个正向输出集中于 174-176，三个互补输出集中于 51/56/57；这已经利用了该封装现有可用的 TIM8 复用位置。高低侧不能都挪到相邻 GPIO，因为互补定时器功能不是任意映射。

这些是 3.3V 逻辑控制信号，不能直接驱动电机或功率 MOSFET。外接门极驱动、功率桥、电流检测和硬件过流保护。三组同属 TIM8，共用周期/频率，分别调占空比，硬件死区也按该定时器约束设置；适合一个三相桥，不等于三套独立频率电机控制器。

按主动高输入、低电平关断的门极驱动接口约定设计时，MOTOR_EN 及六路 PWM 预留合适下拉，保证 MCU 未启动时驱动关闭。若选用主动低驱动器，安全电平必须重新设计，不能照抄下拉。可在逻辑输出源端预留 22-47Ω 串联阻尼位置，根据实际边沿/连线确定是否装配。

过流比较器/驱动器 FAULT 应硬件接入 MOTOR_BKIN，并配合直接关断驱动使能的电路；极性和断线安全状态根据驱动接口设计。软件开启 BKE，设置 BDTR 死区和 OIS/OSSI/OSSR 安全状态，MOE 初始关闭，故障后不要未经确认自动重启。死区按器件开关时间与驱动延迟计算，不在未知功率级的情况下写死一个通用值。参考 [ST 高级定时器说明](https://www.st.com/resource/en/datasheet/stm32f769ii.pdf) 与 [AN4277 PWM 硬件关断](https://www.st.com/resource/en/application_note/an4277-how-to-use-pwm-shutdown-for-motor-control-and-digital-power-conversion-on-stm32-mcus-stmicroelectronics.pdf)。

只需要两组时，保留 U/V，PI7/PB1 不接即可，其他分配无需重做。本次只预留控制口，不代表已完成电机控制系统；多相电流采样、Hall/位置接口和实时任务资源尚未另行分配。现有 TIM3 编码器 PC6/PC7 保持原用途。

## 7. 必须迁移、删除或替换的连接

### 保留功能、改变 MCU 端 GPIO

| 原功能 | 原 MCU GPIO | 最终 GPIO（物理脚） | 外设端处理 |
|---|---|---|---|
| SPI2_CSA | PB4 | PI0（132） | 保留 RN3.4-5 电阻通道；将 RN3.4 的 MCU 端从 PB4 改接 PI0，RN3.5 上的 SPI2_CSA 及其下游不变 |
| SPI2_IRQ | PA8 | PI11（13） | 原 SPI2_IRQ 网络保留，MCU 端移到 PI11，EXTI11 |
| SPI5_IRQ | PA15 | PF10（28） | 原 SPI5_IRQ 网络保留，MCU 端移到 PF10，EXTI10 |
| USER_SW | PG9 | PI8（7） | SW1 端 USER_SW 保留，MCU 端迁移，EXTI8 |
| SD_DETECT | PG14 | PI9（11） | TF1.9 的 SD_DETECT 保留；GPIO 输入 + 去抖轮询，不能占用 PB9 已用的 EXTI9 |

另将 U14.29 以太网 PHY RESET_N 从共享 RESET 网络分离，改接 PC0（32）/PHY_RESET_N，配置独立受控复位及确定的上电电平；主 MCU NRST 和其他 RESET 网络保留不动。PC9 的 25MHz MCO2 时钟保持原分配，固件应建立稳定的 PHY 时钟后再按 PHY 要求释放复位。

### 删除/替换清单

1. 对照历史快照的 20 个外部 LTDC_* GPIO 网标，在本次保存的 MCU 原理图中已经删除，无需重复删。若其他页面仍有无用途的 RGB 总线入口/标签，清理这些显示相关残留；绝不能删除同页 SDRAM 的 FMC 总线。
2. 删除 PG2/U1.110 的 FMC_A12 网标及相应连接，并删除 U9.36/NC 上的 FMC_A12 误接线。U9 仅需要 A0-A11；PG2 改为 LCD_RESET_N。其余 FMC 地址/数据/控制线保持。
3. PD7 上旧 IRQ_TOUCH 已删除，最终增加 SPID_2；触摸 IRQ 只落到 PG7。
4. 按上表移除 PB4、PA8、PA15、PG9、PG14 旧功能的 MCU 侧连接，再接入各自新用途。不是删除这些功能在其他模块上的网标。
5. FPC2.2/3 原直连 I2C1 网名替换为 CTP_SDA/SCL，插入电平转换；EEPROM 侧不改。
6. ESP32 独有 EN 网络统一改名为 ESP_EN，涉及 U18.7、R63、C102、SW2；不要把其他芯片的 EN 一起改名。
7. 删除 U19 R56/R57 造成的跨隔离供电/共地桥接；CAN 隔离侧用新的 +5V_CAN_ISO/GND_CAN_ISO。
8. 删除背光升压输出与 U12.FB/R20 上端之间的错误连接，改为下节恒流反馈。
9. U13/TSC2007 已不在当前图中，不再添加；本屏不使用电阻触摸线、ST7796 的 DB0-15、RS、WR/RD、SPI 显示网或外部 RGB 网。FPC1.40 明确 NC。

保持原脚不动：USB PD4/PD5、PA9/PA11/PA12；OUT2/PB5；UART4 PC10/PC11；编码器 PC6/PC7、PI4；I2C1 PB6/PB7；SWD PA13/PA14 与 SWO PB3；以太网 MII/MCO2；有效 SDRAM FMC 总线；SDMMC1；现有电源控制、SPI2/4/5 总线（只有上表片选/IRQ 迁移）。本配置使用 SWD，不保留完整五线 JTAG。

EXTI 分配：FAULT/PB2=2，ENC_SW/PI4=4，IRQ_TOUCH/PG7=7，USER_SW/PI8=8，SPI4_IRQ/PB9=9，SPI5_IRQ/PF10=10，SPI2_IRQ/PI11=11，RTC_REF/PB15=15。USB_OC/PD4 采用轮询，避免与 PI4 冲突；SD_DETECT/PI9 也轮询。软件 GPIO、EXTI、片选宏和初始化必须同步改，不能只修改原理图网标。

## 8. 背光及上电前必须修正的问题

本屏是七颗 LED 串联，规格书给出 18.9-23.8V、典型 20mA；不能套用低压并联背光的 3.3V 限流电阻方案。U12/TPS61169 可以继续使用，但当前 FB 与升压输出接在一起是错误的。

最终反馈连接：

- D3 阴极 / C58、C59 正端 -> LCD_LEDA -> FPC1.1。
- FPC1.2 -> LCD_LEDK -> U12.3 FB，同时接 R20.2。
- R20.1 -> GND，R20 保留 10Ω，按新版数据手册 204mV 典型反馈电压计算，电流约 20.4mA；若目标更接近 20mA，可选 10.2Ω，并核对反馈误差和电阻公差。
- U12.1 SW 保持与 L1/D3 阳极连接，U12.2 接地，U12.5 接经过输入滤波的 +5V。
- PD12/TIM4_CH1 保持接 U12.4 CTRL，预留约 10k 下拉，默认关背光。PWM 可从 20kHz 开始验证，处于器件支持的 5-100kHz 范围。
- C58/C59 采用至少 50V 额定值并核验直流偏压后的有效容量；当前 ZD1/24V 的接法有悬空，且钳位值靠近正常最高输出，不直接照搬装配。保留方案中先 DNP，若加保护须结合背光开路和驱动器 OVP 重新设计。
- D3 当前 RB751V40 是小信号肖特基，不作为此升压功率整流的默认选型；可以改为 SS16 60V/1A 级器件并更改封装，最终核对漏电/效率/脉冲电流。L1 核对饱和电流和温升。R19 后 U12.VIN 邻近增加输入去耦，不能只有 R19 前的 C57。

反馈阈值、PWM 和保护参考 [TPS61169 数据手册](https://www.ti.com/lit/ds/symlink/tps61169.pdf)，整流器额定参考 [SS16 数据手册](https://www.onsemi.com/download/data-sheet/pdf/ss16-d.pdf)。本节不是不经验证即可替换的完整电源 BOM。

另外，当前 MCU_F7 页 U15/MP1584 的 EN（2 脚）直接接 +12V，超过 EN 所属“其他引脚”的 6V 绝对最大值。上电前必须断开直连，按输入范围/启动门限设计分压或合规使能驱动，不应简单改接该转换器自己的输出造成启动依赖。参考 [MPS MP1584 数据手册](https://www.monolithicpower.cn/cn/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MP1584EN-LF-Z/document_id/204/)。BOOT0/启动锁存、PDR_ON 默认状态也应在最终原生 ERC/上电审查中复核，不能因为 GPIO 表通过就略过。

## 9. 便于布局的放置顺序

1. FPC1 优先靠 U1 的 99-109 脚所在侧，三组 DSI 差分直接短出线。不要为了顺着 FPC 顺序交换 P/N、D0/D1 或拿普通 GPIO 替代。
2. U16/U17 放在 U1 的 151-162 脚附近：MOSI151、CS153、SCK154、CS155、MISO162 成组。PB4 迁出的 SPI2_CSA 改到 PI0/132，与现有 SPI2 的 PI1/133、PI3/134 同一区域。
3. ESP32 数字接口向 PG9/152、PG14/157 和 PD3/145 一侧接近，天线优先靠板边，天线净空按乐鑫要求，不以压缩 UART 长度为由破坏天线区域。
4. 三组 PWM 的正向侧在 174-176，互补侧在 51/56/57，物理上不在同侧，这是保留所有其他模块条件下的复用限制；连接器/缓冲器按真实 PCB 位置安排，不可随意换 GPIO。
5. CAN 隔离器与隔离电源靠 CAN 接口，隔离边界的电气间隙优先于 MCU GPIO 走线长度。低速按键/检测/片选允许绕行，优先把 DSI、时钟、SPI 数据和 SDRAM 布好。

DSI 建议按约 100Ω 差分受控阻抗设计，线宽/间距必须由 PCB 叠层计算；连续参考地，控制对内偏斜及通道间时序预算，减少过孔/支路。不要盲加串联隔直电容、普通 33Ω 阻尼或固定并联 100Ω 终端；DSI 同时有 LP/HS 状态。ESD 器件须适配 D-PHY、低电容。不要为“避免天线效应”把数字回流地挖掉。通用 DSI 布线原则可参阅 [TI DSI 器件布局章节](https://www.ti.com/lit/ds/symlink/sn65dsi83.pdf)，不能照搬其适用于另一芯片的长度容差数字。

目前未找到本 MCU 板的 PcbDoc，因此这里是按 LQFP176 物理脚位和外设复用优化，不是已经验证过的 PCB 最短走线方案。
