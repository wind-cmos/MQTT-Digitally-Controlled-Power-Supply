# ST7796 电容触摸屏换屏与 MCU 重新分配

日期：2026-09-21。主控按现有 U1：STM32F769IIT6 / LQFP176；无线按 U18：ESP32-C3。

结论：建议使用 FMC 16 位 8080 并口。LCD 与 SDRAM 共用 FMC_D0~D15，但使用独立片选；电容触摸使用单独的 I2C 接口，不再使用 TSC2007。可以保留三组外部 SPI、MII 以太网、UART4、1-bit SD、SWD+SWO，并补齐两片升级 Flash、ESP32-C3 和 CAN 的 MCU 引脚。

**不能直接插入旧 FPC1 上电。新旧 40Pin 针序完全不同，当前背光还有反馈接线错误；此外最新 MP1584 的 EN 接 +12V，必须先修正。**

本报告依据用户最新 40P＋6P 图片、CL35BC219-40A_CTP_SPEC_V0、该型号自己的接线图及 FT6336U 手册，并对照重新解析的 6 张已保存 SchDoc。当前 MCU_F7 页保存时间为 17:03:04，SDRAM 页为 17:03:00，USB/LCD 页为 18:40:03；未保存的编辑不在本次范围内。原始 CAD 文件未改动。本报告取代此前 H043A22/GT911、CL35BC1070 及 RGB-LTDC 条件下的分配建议。以下背光参数来自 CL35BC219 本身，不是继承旧屏。

配套：[131 个端口及电源专用脚完整表](D:/桌面/work/project/PCB/AD/数控电源/MCU/ST7796_MCU完整引脚表_2026-09-21.md)。

## 3. 电容触摸 6Pin 与背光 PWM

### 3.1 FT6336U 电容触摸

| 触摸针号 | 屏端名称 | 连接 | MCU 脚号 | 配置 |
|---:|---|---|---:|---|
| 1 | VCC | +3V3 | — | 近连接器 100nF + 1uF 预留 |
| 2 | SDA | PB7 / I2C1_SDA | 165 | AF4、开漏 |
| 3 | SCL | PB6 / I2C1_SCL | 164 | AF4、开漏 |
| 4 | INT | PD7 / IRQ_TOUCH | 151 | MCU 输入 / EXTI7；触发方式匹配 FT6336U 中断模式 |
| 5 | RST | PI8 / CTP_RESET_N | 7 | GPIO 输出，低有效 |
| 6 | GND | 数字地 GND | — | — |

PB6/PB7 保留与 AT24C256 共用 I2C1；已有 R2/R3=4.7k，不要不加检查地又在触摸连接器重复焊一套。建议先以 100kHz 联调，测量上升时间后再提速。该资料包示例使用写地址 0x70、读地址 0x71，即 **7 位地址 0x38**；HAL 需要移位地址时传 0x38 << 1，而不是再把 0x70 左移。复核 EEPROM 地址与总线电容。

FT6336U RESET 低脉冲至少 5ms，手册规定复位后开始上报触摸点至少需要 300ms。可沿用本型号示例的保守流程：PI8 拉低 20ms，拉高后等待至少 300ms，再进行初始化/读取。INT 是触摸到 MCU 的中断信号，不按 GT911 地址选择流程由 MCU 驱动。上电必须满足触摸供电/复位时序；不要在触摸未供电时由 I2C/INT/RST 反向供电。若需要 MCU 尚未启动时也保证复位低，另设计合适的复位监管，不能假定一个弱下拉就能压住 FT6336U 内部上拉。

U13 TSC2007 是四线电阻触摸控制器，**不能驱动电容触摸面板，也不能让普通无触摸 LCD 变成触摸屏**。本方案移除 U13 和旧 XL/XR/YU/YD 连接；C62/C63 可重用于新触摸供电去耦，不必机械地删除所有电容。新增独立 6Pin 连接器，具体间距/触点方向以实物图纸为准。[TI TSC2007](https://www.ti.com/product/TSC2007)

### 3.2 本型号背光：替换原升压驱动

CL35BC219 规格书第 5~6 页确认 6 颗白光 LED 并联，Vf 典型 3.1V、总电流典型 120mA/最大 150mA。本型号接线图为 LEDA 接 3.3V，三个 LEDK 共接后经过 3Ω 到地。可在这个限流参考回路上增加低侧 PWM：

```text
+3V3 -> LCD33 / LEDA -> 屏内 LED -> LCD34、35、36 / LEDK 共接
                                             |
                                            R_BL
                                             |
                                       Q_BL 漏极 D
                                       Q_BL 源极 S -> GND
PD12 / TIM4_CH1 -> 220Ω -> Q_BL 栅极 G
                            |
                          100kΩ
                            |
                           GND
```

- Q_BL 可选 AO3400A，其导通电阻在 VGS=2.5V 已有规格保证，适合 3.3V GPIO 驱动；不是凭栅极阈值判定能否充分导通。封装 G/D/S 按厂家资料核对。[AOS AO3400A 手册](https://www.aosmd.com/res/data_sheets/AO3400A.pdf)
- R_BL=3Ω 是厂家接线图的参考限流值，不是精密恒流 120mA。建议预留至少 0.25W 封装能力，按供电最高值、最低 Vf、阻值容差和温升核算；首次点亮可从 4.7~10Ω 较保守阻值起测，再决定最终值。
- 简化计算 I≈(V供电−Vf−VDS)/R_BL。在 3.3V、Vf=3.1V、忽略 MOS 压降时约 67mA，不能声称 3Ω 就是 120mA。Vf 随电流/温度变化，计算需配合实测；PWM 导通期间总电流也不得超出规格。需要稳定满亮度时，应另选有足够压差余量的恒流方案，3.3V 供电在 Vf 接近 3.3V 时不能保证线性恒流驱动的余量。
- PD12，脚 93，TIM4_CH1 / AF2，保持 TFT_BRIGHTNESS 网络；本低侧方案 PWM 高电平亮、默认低电平关闭。不能由 GPIO 直接供 LED 电流，不能把 LEDK 绕过限流电阻直接接地。
- 移除/不装旧 U12 TPS61169、L1、D3、ZD1 及旧反馈 R20 连接；背光变为新的 3.3V 限流/PWM 回路，合适的电源去耦可保留。旧 5V 输入的升压回路不能给此 3.1V 并联背光作降压恒流供电。[TI TPS61169 手册](https://www.ti.com/lit/ds/symlink/tps61169.pdf)
- 3.3V 电源预算新增约 120mA 典型背光负载，并校核 150mA 上限和稳压器温升。屏逻辑电源与背光供电布线分支处理，背光大电流回流避免经过触摸去耦回路。

## 4. Flash、ESP32-C3、CAN 补齐接线

### 4.1 两片固件升级 Flash：共用 SPI1、各自片选

| 功能 | MCU GPIO / 脚号 | 外设 | 接到现有器件 |
|---|---|---|---|
| FLASH_SCK | PA5 / 51 | SPI1_SCK / AF5 | U16.6、U17.6，原 SPICLK_2 |
| FLASH_MISO | PA6 / 52 | SPI1_MISO / AF5 | U16.2、U17.2，原 SPIQ_2 |
| FLASH_MOSI | PB5 / 163 | SPI1_MOSI / AF5 | U16.5、U17.5，原 SPID_2 |
| FLASH_A_CS_N | PB1 / 57 | GPIO 输出 | U16.1，原 SPICS_2 |
| FLASH_B_CS_N | PH4 / 45 | GPIO 输出 | U17.1，原 SPICS_3 |

两片 W25Q32 作为 STM32 的镜像存储；U20 是 ESP32 自己的启动 Flash，不合并到这条 SPI1 总线上。当前 U16/U17 的 CS 已分开，不再列为“同片选”错误，但它们还没有接入 MCU。

每个 CS# 加独立约 10k 上拉，初始化时先保持两个片选为高；同一时刻只选一片。当前 WP#/HOLD# 上拉在标准 SPI 方案下可保留；每片就近 100nF 去耦。先低速验证 JEDEC ID、擦写和 CRC，再提高时钟；Bootloader 自身留在 MCU 内部受保护区。两片镜像和升级状态元数据仍需掉电恢复设计，这不是只焊两片 Flash 就自动有可靠 A/B 升级。

### 4.2 ESP32-C3 通信与恢复下载

| 功能 | MCU GPIO / 脚号 | 外设 | ESP32-C3 连接 |
|---|---|---|---|
| 主控发送 | PG14 / 157 | USART6_TX / AF8 | U18.27 / U0RXD |
| 主控接收 | PG9 / 152 | USART6_RX / AF8 | U18.28 / U0TXD，经现有 R49 |
| ESP_EN | PG7 / 115 | GPIO 开漏 | U18.7 / CHIP_EN，与现有 RC/复位按键共接 |
| ESP_BOOT_N | PI0 / 132 | GPIO 开漏 | U18.15 / GPIO9，增加约 10k 上拉并预留下载按键/测试点 |

现有 EN 已加 10k、100nF 和按键，不再是悬空；电容取值应根据实际电源上升与官方时序复核，而不是把已有电路忽略。GPIO2/GPIO8/GPIO9 的启动绑带要按 ESP32-C3 指南处理。上电时 MCU 开漏控制脚释放，不能无意把 C3 保持在复位/下载态。

RF 端还需完整天线/连接器、匹配与 50Ω 布局；U20 目前 IO2/IO3 未接回 C3，应明确只用 DIO，或补全 QIO 连线与配置。C3 发射瞬态与其他器件总电流一起核算 3.3V 电源。[Espressif 硬件设计检查表](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32c3/schematic-checklist.html)

### 4.3 CAN3 + CA-IS1044S

| 功能 | MCU GPIO / 脚号 | 配置 | U19 连接 |
|---|---|---|---|
| CAN 接收 | PA8 / 123 | CAN3_RX / AF11 | U19.3 / RXD |
| CAN 发送 | PA15 / 138 | CAN3_TX / AF11 | U19.2 / TXD |

软件必须使用 **CAN3**，不是沿用 CAN1 初始化。PA15 不再用于完整 JTAG，仍保留 PA13/PA14 的 SWD 和 PB3 的 SWO。TXD 预留约 10k 上拉至 VCC1，避免 MCU 复位时持续显性输出。F769 内置的是经典 CAN 2.0 控制器，换隔离收发器不等于支持 CAN FD。[ST STM32F769 数据手册](https://www.st.com/resource/en/datasheet/stm32f769ni.pdf)

U19.1=主板 3.3V，U19.4=主板 GND；**U19.8 必须获得相对 U19.7 的 4.5~5.5V**。建议本板用隔离 DC/DC 产生 +5V_CAN_ISO 和 GND_CAN_ISO，两侧各就近 100nF 去耦。R56 不能继续桥到主板 3.3V，R57 不能继续桥到主板 GND，否则电压不合要求且隔离失效。CANH/L 和隔离侧参考地、保护器件留在隔离侧；终端 120Ω 仅在总线端点使能。[CA-IS1044S 手册](https://e.chipanalog.com/Public/Uploads/uploadfile/files/20240611/CAIS1044SdatasheetVersion1.05en.pdf)

## 5. 为消除引脚冲突必须迁移的旧功能

| 原网络 | 原 MCU 引脚 | 新 MCU 引脚 | 说明 |
|---|---|---|---|
| OUT2 | PB5 | PB0，脚 56 | 释放 PB5 给 SPI1_MOSI |
| SPI2_IRQ | PA8 | PI5，脚 174 | EXTI5；释放 PA8 给 CAN3_RX |
| SPI5_IRQ | PA15 | PI6，脚 175 | EXTI6；释放 PA15 给 CAN3_TX |
| USER_SW | PG9 | PI10，脚 12 | EXTI10；释放 PG9 给 USART6_RX |
| SD_DETECT | PG14 | PG6，脚 114 | 使用轮询；释放 PG14 给 USART6_TX |
| USB_OTG_FS_OC | PD4 | PI11，脚 13 | 输入，可使用 EXTI11；检查 OC# 上拉 |
| USB_OTG_FS_PSO | PD5 | PG11，脚 154 | 输出，默认关闭；USB 供电用途仍需确认 |

改 MCU 页的网标并同步修改固件即可保留接口侧原网络名；不要同时留在新旧两个 MCU 脚上。原 SPI4_IRQ/PB9 保留为 EXTI9，避免再把其他 Px9 配成另一个 EXTI9 源。SD_DETECT/PG6 不用 EXTI6，因为 PI6 已占用该中断选择线路。

新增 **PD3 / 脚 145 = PHY_RESET_N**，连接 U14.29。将 PHY_RESET_N 从 MCU 的 RESET/NRST 网络断开，独立上拉/受控复位；先建立 PC9/MCO2 的有效 25MHz 时钟，再按 PHY 时序复位并初始化。PC9 保留，不转 SDMMC1_D1；SD 卡继续 1-bit。MII、外部 SPI2/SPI4/SPI5 及 UART4 的其余信号保持现状。

引脚方案仍预留 PA10、PF10、PG10、PI7、PI9。显示第 8 脚在模块规格书中是 TE 输出，但本方案保持 NC。如果以后接 PA10 并使用 EXTI10，必须将 USER_SW/PI10 改为轮询或迁移中断；两个 Px10 不能同时成为 EXTI10 的输入源。同理 PI7 的 EXTI7 与触摸冲突，PI9 的 EXTI9 与 SPI4_IRQ 冲突，不能只看 GPIO 空闲就认为外部中断也空闲。

## 6. 软件 / CubeMX 配置要点

| 模块 | 推荐配置 |
|---|---|
| 显示 | 关闭旧 LTDC 初始化；启用 FMC 异步 16-bit SRAM/NOR 接口驱动 8080 LCD |
| LCD 控制 | NORSRAM Bank1 的 NE4 子区，即 HAL 常量 FMC_NORSRAM_BANK4；非地址数据复用；不使用 NWAIT；异步读写 |
| LCD 寄存器选择 | PG2/FMC_A12，不是普通手动翻转 RS GPIO |
| SDRAM | 维持独立 SDRAM bank/片选及原有时序；与 LCD 共用 FMC 时钟和数据引脚初始化 |
| 触摸 | FT6336U，I2C1、PB6/PB7；7 位地址 0x38；PD7 INT，PI8 RESET |
| 背光 | TIM4_CH1 / PD12；第 3.2 节 NMOS 方案为高电平亮，初始占空比 0；频率结合波形/开关损耗/EMC 验证 |
| 升级 Flash | SPI1 主机，软件 NSS，两个 GPIO 片选，先低速联调 |
| ESP32 | USART6 异步全双工，TX/RX 交叉，暂不占用 RTS/CTS |
| CAN | CAN3，PA8 RX、PA15 TX；按 APB 时钟和目标波特率计算位时序 |
| 调试 | SWD + SWO，不开完整 JTAG |

默认 FMC 内存映射、未做 SWP_FMC 重映射时，NE4 基址为 0x6C000000。因为总线宽 16 位，外部 A12 对应 CPU 字节地址 A13，因此接线推导为：

```c
/* 地址仅适用于本报告的 NE4 + A12 + 16-bit、未重映射方案。 */
#define LCD_CMD  (*(volatile uint16_t *)0x6C000000UL)
#define LCD_DATA (*(volatile uint16_t *)0x6C002000UL)
```

命令/数据访问使用合适的半字操作，不能用任意宽度的 memcpy 代替。LCD 区域用 MPU 配为设备型、不可缓存、禁止执行，避免普通内存缓存/推测访问对屏幕寄存器产生副作用。带 DMA 的帧缓存按 M7 D-cache 一致性要求处理；若用普通 DMA 搬像素，目标 LCD_DATA 地址固定。DMA2D 可用于渲染，但不要默认它可不改配置地替代固定地址的 8080 写流。

FMC 读写建立/保持、总线换向、写 FIFO 与访问模式需要结合 HCLK、SDRAM 共总线负载验证；这里不把未经计算的 CubeMX 数值当最终值。模块规格书第 10~11 页给出的写周期至少 66ns，WR 低/高分别至少 15ns；寄存器读与帧存储读时序不同，不能简单照抄写时序。LCD 与 SDRAM 的 HAL MSP 初始化/反初始化不要相互关闭时钟或释放共用引脚。UI 使用 320×480（横屏 480×320），MADCTL/COLMOD、初始化寄存器表及触摸坐标旋转按新模块及实际控制器版本更新，不套用 ILI9488/NV3041 程序。
