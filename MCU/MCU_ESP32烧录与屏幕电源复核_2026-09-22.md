# MCU 复核：ESP32 烧录与 PANEL_PWR_EN

本次只读取六张保存的 SchDoc，不修改 CAD。快照：`tmp/mcu_review_panel_20260922/source_manifest.json`。此文更新旧报告中已经修复的状态，但不是原生 Altium ERC、PCB 或整机测试合格证明。

## 1. 结论与已完成项

- STM32F769IIT6 可以通过 USART6 + 两根 GPIO 给 ESP32-C3 烧录。最新原理图四根线均已接通，下载可靠性还需修复 GPIO8 偏置和 GPIO9 电容。
- `PANEL_PWR_EN` 仅存在于 U1.PH4/45，目前没有独立屏幕电源器件接收它。它应接新增屏电源的 EN，不直接接 FPC 电源脚。
- U1 物理脚 1-176 与 ST 官方封装定义一致；123 个规划 GPIO 的 MCU 端网络与无电机目标一致（含 RN 串阻追踪）。8 个备用脚为 PA5、PA6、PB0、PB1、PI5、PI6、PI7、PI10。
- PB4 经 RN3.4-5 接 SPIQ_2、PB14 接 SPI2_MISO，已修复 SPI 总线混接；PI0 直接接 SPI2_CSA 可保留。
- PG9/PG14 的旧 USER_SW/SD_DETECT 网标已移除，PD12 背光、FPC2.5 触摸 INT 已接通。
- C60=2.2uF 已连接 VCAPDSI/VDD12DSI 到地。
- BOOT0 不再硬短接 GND，R5 已改为 10k 下拉；但 U7 输出仍连接 BOOT0，尚未完全处理。
- MP1584 EN 已由 R56=20k 上臂、R57=10k 下臂分压，12V 标称时约 4V；这不是可接受任意高输入的钳位，必须核算最大输入及瞬态。
- CAN 两个跨隔离 0Ω 桥已移除，改为 U21 引出总线侧电源/地/CANH/CANL。
- 当前未发现跨页重复位号或带问号的未注释位号。

## 2. STM32 给 ESP32-C3 烧录

| STM32 引脚 | 模式 | 网络 | ESP32-C3 引脚 | 当前 |
|---|---|---|---|---|
| PG14 / 157 | USART6_TX / AF8 | U0RXD | U18.27 GPIO20/U0RXD | 已接通 |
| PG9 / 152 | USART6_RX / AF8 | U0TXD | U18.28 GPIO21/U0TXD，经 R49=499Ω | 已接通 |
| PD3 / 145 | GPIO 开漏，默认释放 | ESP_EN | U18.7 CHIP_EN | 已接通 |
| PA10 / 125 | GPIO 开漏，默认释放 | ESP_BOOT_N | U18.15 GPIO9 | 已接通 |

必须修改：

1. C103=1uF 当前跨接 ESP_BOOT_N 与 GND。删除或 DNP；GPIO9 是启动配置采样脚，不能照搬 EN 的大电容延时电路。保留 R64=10k 上拉与 SW3 下拉按钮。
2. U18.14 GPIO8 当前悬空，增加 10k 上拉至 3.3V；下载采样时必须为高。
3. U18.6 GPIO2 当前悬空，按官方建议加 10k 上拉至 3.3V；GPIO2 不是实际决定这两种启动模式的位，但建议避免毛刺。
4. C102=1uF 是 ESP_EN 上的 RC 延时，可以保留；与 C103 的用途不同。R63=10k、SW2 保留，实际验证 EN 上电/复位波形。
5. 固件中 PD3/PA10 使用开漏输出。ODR=1 表示释放，由外部上拉形成高电平；不要与按钮进行推挽高电平争用。

程序流程：先用 H1/SWD 把下载功能烧入 STM32；STM32 获取匹配 ESP32-C3 的完整固件包，控制 GPIO9 低和 EN 复位，等待 EN 真正上升后的启动采样及 ROM 就绪，再通过 USART6 下载、校验；结束时释放 GPIO9 并再次复位。推荐移植乐鑫 esp-serial-flasher 的 STM32 host/UART port，不是把普通业务串口数据直接发送就能烧录。

ESP32-C3 自带 ROM 下载程序，不要求外部 Flash 中先有应用。固件应写入 U20=W25Q32（4MB），不是 U16/U17 的 STM32 A/B 镜像槽。当前 SPIHD/SPIWP 未接 U20，按 DIO 构建，不要使用 QIO。升级文件及偏移取自该 ESP32 工程的构建产物；不要照搬其他型号的地址。

UART0 同时承载 ROM 日志/下载；如果业务也复用这一对脚，STM32 协议需能忽略启动日志并区分下载态。现成 ESP-AT 的应用串口映射不一定与 ROM UART0 相同，应确认或定制。

### 外部烧录接口 U13

当前 U13.1=ESP TX，.2=ESP RX，.3=板载 3.3V，.4=GND。它配合 SW2/SW3 可以做手动下载口，不必为此重做六针口。需要自动控制时再引出 EN/BOOT 测试点。

PC 下载器 RX 接 U13.1，TX 接 U13.2，GND 接 U13.4。默认整板独立供电，U13.3 标注 3V3/VTREF，不能误接 5V 或未经择源就并接另一台 3.3V 电源。

U13.2 与 STM32 PG14 当前直连，外部下载器 TX 会和 STM32 TX 并联。建议改成 `PG14 -> MCU_ESP_TX -> 可断开跳帽/0Ω -> U0RXD -> U18.27、U13.2`。串阻两侧不能仍都叫 U0RXD，否则同名网络会绕过断开点。外部下载时断开，或可靠保证 STM32 PG14 全程输入高阻且不执行任何串口发送。单纯增加几十欧姆不是电气隔离。

## 3. PANEL_PWR_EN 的正确连接

它来自 PH4/物理 45 脚，是 3.3V 逻辑控制信号，配置 GPIO 推挽、初始低。新增独立 LDO/负载开关，由 EN 控制输出。它不是 LCD 标准 FPC 信号。

推荐结构：

```text
主板 +3V3 -> LCD 专用 2.8V LDO -> +VDD_LCD -> FPC1.3、FPC1.38
                     EN <- PANEL_PWR_EN <- PH4/45

主板电源 -> 触摸专用稳压/开关 -> +VDD_CTP -> FPC2.4、C62、C63
                     EN <- PANEL_PWR_EN（允许共控时）

PD12/TFT_BRIGHTNESS -> U12.4 CTRL -> 背光 LEDA/LEDK，保持单独控制
```

### LCD 支路具体候选

按现有文档的电气表预留 2.8V，候选 **TPS7A2028PDBVR，SOT-23-5/DBV**。这是候选设计，不是已有器件，也不等于供应商的电压冲突已经解决。

| 该型号物理脚 | 名称 | 接线 |
|---:|---|---|
| 1 | IN | 主板 +3V3 |
| 2 | GND | 主板 GND |
| 3 | EN | PANEL_PWR_EN；可预留 100k 下拉保证关断默认态 |
| 4 | NC | 不连接 |
| 5 | OUT | 新网络 +VDD_LCD，接 FPC1.3 与 FPC1.38 |

输入就近放 1uF，输出预留 2.2uF X7R 并保证偏压/温度/公差后至少满足器件 1uF 有效容量要求；屏接口附近再放 100nF。300mA 为器件额定能力，不代表负载预算已测量。LCD 文档逻辑电流最大值列 60mA，不包含背光；背光继续由 U12 负责。不能把 +VDD_LCD 再通过其他同名电源端口并回 +3V3。

FPC1.38 是模式选高，随屏供电拉高到厂家确认的屏 IO 电平；目前方案暂按与 LCD VDD 相同的 2.8V 处理，仍须供应商确认该模组的内部 IOVCC 连接。39 接 GND 不变。PH4 不接 38 作动态模式控制。

### 触摸支路和关断反灌

- FPC2.4 从主板 +3V3 改为独立命名的 +VDD_CTP，C62/C63 电源端一起改；不要默认与 +VDD_LCD 合并。
- FT5X16 芯片手册的 VDDA/VDD3 范围为 2.8-3.6V；2.8V 是下限，若选标称 2.8V LDO，负公差就可能低于下限。触摸电压、内部 IOVCC 接法和接口耐压应按实际模组确认，再选择有容差裕量的供电。不能仅凭裸芯片范围断言模组可直接接主板 3.3V。
- 若 LCD/触摸允许同启停，PH4 可连接两个器件 EN；若需要触摸唤醒，不应随 LCD 一起断触摸电源，应另控或常供。
- R2/R3 目前把共享 I2C1 拉到主板 3.3V，EEPROM/外部接口也在此总线上。不能为了关触摸电源而把整个共享总线的上拉改接到关断电源。
- 在触摸支路预留具有断电高阻的电平转换器，例如 TCA9406：主板侧 3.3V，触摸侧接确认后的 IO 电压；避免触摸关电后经 SDA/SCL 反向供电。INT 也应核对输出电平与断电行为，必要时做单向转换。
- PG2/LCD_RESET、PG6/LCD_FC_RESET 用开漏并上拉到对应模块 IO 电源，不用主板 3.3V 推挽硬顶已断电的屏。
- MIPI DSI 差分对不经过普通 GPIO/I2C 电平转换器；屏掉电前停止视频并按 DSI/屏幕要求进入安全状态。
- 上电顺序：背光关、复位有效 -> PH4 高 -> 等电源稳定 -> 按屏厂家初始化/复位时序 -> 有效图像后开背光。关机先关背光并处理总线，再断电。延时按模块初始化资料，不在此臆定固定数值。
