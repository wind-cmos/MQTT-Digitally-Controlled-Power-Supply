# MCU 无电机版：当前电路复核及修改清单

> 2026-09-22。以本次保存的六张 SchDoc 为准，未回写原理图/PCB。主控 STM32F769IIT6 / LQFP176，ESP32-C3，D350T1013V1 MIPI 电容触摸屏。此版取消 MOTOR/TIM8，不再沿用上一版电机引脚表。

## 结论

目前不能判定“电路无误、每个引脚均正确配置”。显示接口已有多项修正，但仍有错接、重复网标、漏接、供电和启动问题。下列是实际连接检查与修正方案，不是已完成的 CAD 更改。

已经给全部 176 个 MCU 物理脚明确去向：123 个规划使用的 GPIO（含时钟/调试）、8 个备用 GPIO、45 个电源/专用脚。备用脚设 Analog/NoPull、不启用 TIM8，不必强行接上功能。

没有 .ioc 或固件可供核查，所以“配置表”不意味着固件 GPIO/AF 已经实现。USB 角色和功率控制信号的上电有效极性仍需整机确认；这些项在表中明确标注，不通过猜测填满。

## 2. 上电前必须处理的电路问题

### B01. BOOT0 与地短接，同时被 U7 输出驱动

本次 MCU_F7 原始记录及局部重绘均显示，BOOT0 导线与 C1 下端 GND 直接相连；R5 两端也被并到同一地网。IO_Connectors 页 U7.3/Q# 仍贴 BOOT0。跨页连接后，U7 推挽输出可能对地驱动，不能把“BOOT0 默认低”理解成这种硬短接。

建议简化为：

1. 删除 BOOT0 导线与 C1/GND 的直接连接，C1 本身继续接地。
2. 断开 U7.3 与 BOOT0；若不再需要锁存逻辑，U7 及其专属去耦可 DNP，SW1/USER_SW 保留作用户按键。
3. R5 改约 10k，下端 GND，上端独立 BOOT0；增加可拉高到 3.3V 的独立跳帽/按钮用于救援。
4. BOOT0 常低不影响内部 Flash Bootloader 加载外部镜像；不要把 ESP_BOOT_N 接入 STM32 BOOT0。

U7 原来的 D 固定高、置位/复位均无初始化控制，也不是可靠的“每按一次翻转”电路。若坚持保留 U7，需要重设计启动和按键状态，不建议仅改网名。

### B02. U15 / MP1584 的 EN 仍直接接 +12V

U15.2/EN 与 U15.7/VIN 同为 +12V。器件 EN 属于最大 6V 的引脚，必须断开直连，按实际输入范围设计分压/使能驱动，并校核阈值和阻值公差。不要简单接到该转换器自己的 5V 输出造成启动依赖。当前 R39=210k、R41=40.2k 对应约 4.98V 的输出反馈本身不必因本项重改。

依据：[MPS MP1584 数据手册](https://www.monolithicpower.cn/cn/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MP1584EN-LF-Z/document_id/204/)。

### B03. CAN 隔离侧供电仍不正确

U19.8/VCC2 经 R56=0Ω 接主板 3.3V；U19.7/GND2 经 R57=0Ω 接主板地。CA-IS1044S 总线侧需要 4.5-5.5V；共地又破坏隔离。

将 R56/R57 的跨边界桥接删除，使用 +5V_CAN_ISO/GND_CAN_ISO；主板侧 U19.1/4 保持 3.3V/GND。增加两侧各自 100nF 局部去耦，预留总线侧保护/连接器。R58=120Ω 仅总线端点装配。CAN_RX/TX 引脚分配本次已正确，不等于隔离电路已经完成。

依据：[CA-IS1044S 数据手册](https://e.chipanalog.com/Public/Uploads/uploadfile/files/20240611/CAIS1044SdatasheetVersion1.05en.pdf)。

### B04. DSI 内部 1.2V 节点缺少 2.2uF

U1.100/VCAPDSI 和 U1.106/VDD12DSI 已相连，但该节点只有两个芯片脚，没有电容。新增 2.2uF 到 GND，就近布置。U1.99/VDDDSI 继续用主板 3.3V；该电源与模组的独立 LCD 电源不同。U1.103/109 接地。

PDR_ON/U1.171 当前只通过两针 H2 才可能接 3.3V；未安装跳帽就会悬空。使用内部 POR/PDR 时建议固定连接 VDD，或 0Ω 默认装配。BYPASS_REG 的 R6=10k 下拉保留。依据：[STM32F769 数据手册](https://www.st.com/resource/en/datasheet/stm32f769ii.pdf)。

### B05. 屏幕供电又直接接到了主板 3.3V

当前 FPC1.3/38、FPC2.4 和触摸 I2C 均直接用主板 3.3V。先前用户已明确商家未确认电压，要求保留独立屏电源，因此当前接法还不能认可。

- FPC1.3/38 -> +VDD_LCD；FPC2.4 与 C62/C63 -> +VDD_CTP。
- PH4/PANEL_PWR_EN 控制独立电源，默认关闭。LCD 可先预留 2.8V 可配置方案，最终装配值、触摸 VDD 和 IO 电平以模组厂确认结果为准。
- LCD_RESET、LCD_FC_RESET 设开漏，各自上拉到确认的 IO 电压，不用 MCU 3.3V 推挽直驱。
- FPC2 的 SDA/SCL 独立命名 CTP_SDA/CTP_SCL，经过 TCA9406 等适配器后接主板 I2C1。INT 预留 SN74LVC1T45 等合适转换。电源关闭时还要避免接口反灌。
- 不对 DSI 高速差分线使用这些普通逻辑电平转换器。

依据本地屏规格书第 6 页（LCD VDD 2.7-2.9V、IO 1.8/2.8V）、第 7 页（针脚表写 2.8-3.3V）之间的冲突，不能擅自挑一项作结论。

### B06. PHY 49.9Ω 已添加，但公共端没有直流偏置

当前 R36/R61 公共端只连 C99；R37/R62 公共端只连 C100。这两个节点都没有连电源。电容接地不提供所需的直流偏置。

按 DP83848C 图 7-2 和布局说明，把两组电阻公共端接规定的 3.3V PHY 偏置电源，保留电容到地；检查磁性器件中心抽头对应供电。U14.20/21 的 2.2k 上拉应参考 AVDD33。U14.23/PFBOUT 的主去耦当前为 4.7uF，应按厂家 10uF+100nF 要求复核，PFBIN 的局部 100nF 分别就近。

PC0 预留 PHY_RESET_N；先建立 PC9/MCO2 的 25MHz 时钟，再释放 PHY 复位，避免依赖 MCU 共享 NRST 的上电时序。U14.8-12 对 DP83848C 是厂家要求不连接的脚，不要为了“每脚都有用”强接。

依据：[TI DP83848C 数据手册](https://www.ti.com/lit/ds/symlink/dp83848c.pdf)。

## 3. 已改善的项目，不需要重复撤销

- DSI 六根专用线与 FPC1.5/6/8/9/11/12 针序一致，LCD_RESET 与 LCD_FC_RESET 两端也已连接。
- FPC1 的 MIPI 地脚已连地，40/NC 保持不接；38 高、39 低的物理模式针序正确（供电电压另议）。
- 背光反馈已修正：U12.3/FB、R20 上端与 FPC1.2/LEDK 同网；LEDA 与 FB 已分离。
- U9.36/NC 的 FMC_A12 误接已删除；PG2 已改 LCD_RESET。地址总线文字可同步从 A[0..12] 改为 A[0..11]，避免误导。
- SDRAM 的 UDQM 和地脚、SWD、以太网 MII 数据复用、CAN3 信号引脚已保留。
- SPI2_IRQ -> PI11、SPI5_IRQ -> PF10 已完成；PI8/PI9 新网标已加，但旧 PG9/PG14 网标还要删。
- ESP32 EN 已有 R63、C102 和 SW2，不再是“完全悬空”；仍需接 STM32 控制和验证上电 RC。

## 6. 检查方法和限制

对本次六张 SchDoc 的原始记录做只读连接提取，电阻阵列两端单独追踪；对照 ST 官方封装/复用 XML 检查 U1.1-176。对 BOOT0 区域用当前原始记录重新绘图，避免引用陈旧 Altium 缩略图。保存时间与 SHA-256 已写入完整引脚表。

建议表已通过：全部物理脚覆盖、GPIO/AF 合法、每项分配唯一、123 使用+8备用、DSI 六线针序和 EXTI 不冲突。当前电路的 A/B 类错误被明确保留为待改，不会因建议表通过就标为原理图通过。

未做：Altium 原生 ERC、固件/CubeMX 时钟和 DMA 分配、实际电源负载与稳定性、PCB 叠层/布局/阻抗、FPC 封装接触面、RF 调谐、点屏或整机实测。没有 MCU 板 PcbDoc；不能保证只凭原理图审核整机可用。
