# MCU 全引脚检查与分阶段改脚建议（2026-09-28）

基于本次磁盘保存版，未修改 SchDoc/PcbDoc。此报告替代此前改脚建议；尤其 ETH_RESET_N 本版安排到 PI6，PI8 用于 SD_DETECT。

范围：MCU 工程 7 张 SchDoc、STM32F769IIT6/LQFP176 的 176 个引脚及同名跨页端点。辅助几何解析不是 Altium 原生编译；未检查 PCB 实际走线、固件、DMA 分配、实测波形或全部器件电气参数。网络存在不等于功能合格。

## 1. 当前结论及必须修正项

- 176 个封装脚完整，名称与 ST 封装数据库匹配。121 个已分配 GPIO、10 个空闲 GPIO、45 个电源/专用脚；当前已分配 GPIO 的所用功能通过 AF 数据核对。
- PG9/152 当前是 USER_SW，而 ESP 发出的 U0TXD 只到 R49 和 H2，不再到 MCU。恢复 PG9=U0TXD（USART6_RX），将 USER_SW 移到 PB0/56。PG14/157=U0RXD（USART6_TX）不变。命名是 ESP 视角，不要接成 TX 对 TX。
- BOOT0 同时连接 MCU R5=10k 下拉、SW1 经 R71=1k 到 +3V3，以及新增 U?? 74AUP1G74 的 Q#。D=1，置位/复位脚均为高，CP 上升沿后 Q#=0；不是往返切换，也不能保证上电即低。Q# 为主动输出，SW1 不能可靠覆盖它。建议移除/不装此触发器并断开 Q#→BOOT0，保留 USER_SW 的按键/10k 上拉/10nF，以及独立 BOOT0 救援按键。仅移除触发器不等于删除 USER 按键。
- BOOT0 留作 ROM 救援：保持 R5 下拉及 SW1+R71；按住 BOOT0 按键后复位/重新上电，按对应启动配置进入系统存储器。正常在线升级由 Flash bootloader 管理，不依靠触发器驱动 BOOT0。
- SD 当前 D0、CMD、CK、CD 均有 MCU 端点；D1/D2/D3 只有卡座和外围元件，无 MCU 端点。阶段 A 必须保持 1 位模式。
- SDMMC1_CMD 仍缺外部上拉：增加 10k 到 +3V3。SD_DETECT 建议增加 10k 到 +3V3，并核对卡座检测开关另一端能否接到数字 GND。
- TF1 的 10~13 脚当前经 R76=1M 并联 C109=1nF 接 PE，未直接接数字 GND。如果 CD 开关另一端是外壳，这种连接不能保证检测低电平；必须核对准确卡座料号/实际通断，不能仅靠改 GPIO 解决。
- SD 保护器件现已是 D8~D11 H5VL10B，不再是此前的 SMBJ5.0CA。本报告不沿用旧型号结论；需按实际厂家资料验证电容、钳位及装配。
- 当前 CANH/CANL 上 ESDS311 是 3.6V 单向保护器件，需重新核对 CAN 的正负共模及故障电压兼容性，不能仅按 3.3V MCU 逻辑电平选总线侧保护。CAN 改脚不会消除此电气风险。
- 新增器件仍存在 U??/SW?/R?/C?/D? 等未注释或重复位号，更新 PCB 前统一编号。

| PG9/152 | USER_SW | U0TXD / USART6_RX / AF8_USART6 |
| PB0/56 | 未连接 | USER_SW / GPIO |

| PH5/46 | FMC_SDNWE | I2C2_SDA / I2C2_SDA / AF4_I2C2 |

两组总线分配建议：I2C1 PB6/PB7 保留 U5/CN1 外接设备；I2C2 PH4/PH5 用于板内 U10 EEPROM 与 FPC2 触摸。若只想增加新接口，可保持 U10/FPC2 在 I2C1，但必须将 I2C2 真正引到连接器/测试点，不能只在 MCU 页加标签。

若分流 U10/FPC2：仅在这两个目标电路中将 SCL/SDA 标签改为 I2C2_SCL/I2C2_SDA，包含随网络移动的上拉；不要全工程替换 I2C1。每条独立总线分别核算并联上拉，按供电、速度、总线电容选值。上拉应接该段器件兼容的逻辑电源。

ETH_RESET_N 从 PC0 移到 PI6，FMC_SDNWE 从 PH5 移到 PC0，仅改 MCU 侧端点，PHY RESET_N、SDRAM WE# 端网络名不变。两者原有初始化顺序与上电状态必须保持。

## 3. 阶段 B：确需更高 SD 带宽时，在 A 基础上实施

保留 SWD 和 SWO，不再使用上一版“CAN_RX 占用 PB3”的方案。CAN3 改 CAN1，UART4 改 USART2；网络名称保持，修改 MCU 引脚与固件外设实例。

最终 SDMMC1：PC8/121 D0，PC9/122 D1，PC10/139 D2，PC11/140 D3，PC12/141 CK，PD2/144 CMD，均为 AF12；PI8/7 为卡检测 GPIO。卡座 TF1 的 D0/1/2/3 分别是 7/8/1/2 脚，CMD=3、CLK=5、VDD=4、VSS=6、CD=9。

MCLK_25 改由 PA8 的 MCO1 输出：核对 HSE 实际频率，选择可精确生成 25MHz 的源/分频；稳定后再释放 PHY 复位。不能只把 MCO2 引脚设置复制到 MCO1。

USB_OTG_FS_PSO 从 PD5 移到 PI7，USB 电源开关 EN 及 R42 下拉保持；PWR_DIRECT 从 PD6 移到 PI10，CN1.10 不变，并保持输出安全默认态。选择 PI10 而非 PA6，是保留与原 PD6 相近的 FT 数字接口类别；FT 不代表任何模式/掉电状态都允许 5V，仍须核对外部电平。USART2 TX/RX 分别改至 PD5/PD6；原 UART_TX/OUT1、UART_RX/DIN1 的 GPIO 复用模式也要跟随变更。

CAN_RX 从 PA8 移到 PI9，CAN_TX 从 PA15 移到 PB9，收发器 U7.3/U7.2 网络不变。SPI4_IRQ 从 PB9 移到 PI5，连接器 U5.10 不变。CAN3 的初始化、时钟、中断、位时序、过滤器改为 CAN1；这是控制器实例迁移，不只是换 GPIO。

阶段 B 后未用脚为 PA5、PA6、PD4、PA15。PA5/PA6 不是刻意保留：现有信号已经安排完，不需要为了用满脚而增加无需求功能。它们是 TTa 模拟能力引脚，不应不加检查地替代 FT 引脚接外部信号。可按后续需求使用；未用时配置合适的低功耗输入状态。PI5/PI6/PI7/PI10 已全部用于实际功能。

## 4. EXTI 规划：避免同一编号占用两路输入

不同端口的同编号 GPIO 不能同时选为同一条 EXTI 的输入；不同 EXTI 线共用一个 NVIC 向量则可以，在 ISR 中区分挂起位。最终建议：

| 输入 | 阶段 B GPIO | EXTI |
|---|---|---:|
| USER_SW | PB0 | 0 |
| USB_OTG_FS_OC | PB1 | 1 |
| FAULT | PB2 | 2 |
| ENC_SW | PI4 | 4 |
| SPI4_IRQ | PI5 | 5 |
| UART_RX/DIN1（仅 DIN1 边沿输入模式） | PD6 | 6 |
| LCD_EXTI7 | PG7 | 7 |
| SD_DETECT | PI8 | 8 |
| SPI5_IRQ | PF10 | 10 |
| SPI2_IRQ | PI11 | 11 |
| DIN2 | PC13 | 13 |

ENC_A/ENC_B 保留 PC6/PC7，使用 TIM3 编码器模式，不再同时配置同编号 EXTI。阶段 A 中 SPI4_IRQ 仍在 PB9/EXTI9；SD_DETECT 已移到 PI8，避免原来的 EXTI9 冲突。USB_OC 移到 PB1，避免 PD4 与 PI4 按键共享 EXTI4。阶段 A 若保留 PC11 的 DIN1 边沿中断，会与 PI11 的 SPI2_IRQ 冲突；DIN1 轮询可用，若必须独立边沿中断，应提前实施阶段 B 的 USART2/USB_EN/PWR_DIRECT 迁移四项。

## 5. 保持不变的功能与验收

- SDRAM 除 FMC_SDNWE 改 PC0 外，地址/数据/其余控制脚不变；改线后检查 WE# 路由、时序并运行全容量读写测试。
- SPI1 Flash、SPI2/SPI4/SPI5 总线及片选不变；SPI4_IRQ 阶段 B 迁移。ESP TX→MCU RX 必须先恢复。
- 以太网 MII 数据/控制接口不变，仅复位 GPIO 迁移，阶段 B 再迁移 25MHz 时钟输出。
- DSI、触摸中断/复位、背光 PWM、蜂鸣器输出、USB D+/D-、VBUS 检测、BOOT0/NRST、晶振、电源/VCAP 接法不因本次分配而变更；这不代表其电气参数已全部通过。
- SWD PA13/PA14、SWO PB3 保留；不承诺恢复完整 JTAG，因为其他 JTAG 复用脚原本已有用途。
- SD 初始化先用低速/1位，卡和主机协商后再切4位；最高频率按卡类型、MCU时钟、电气时序决定。相同频率下理论数据线带宽为4倍，实际文件吞吐不保证4倍。
- STM32F7 使用 SD DMA 时，确认 DMA 可访问的缓冲区、D-cache 清理/失效及缓存行对齐，不能将所有读写错误都归因于引脚。
- 安全输出先设定正确默认值再开启驱动；PHY 时钟与复位有序初始化，CAN TX 空闲态和未初始化状态按收发器需求检查。
- 执行 Altium 编译/ERC/ECO，确认网络作用域以及所有迁移信号只连接到一个目标 MCU 脚；CubeMX 校验引脚/时钟/DMA/中断；随后分项实测 SDRAM、ESP 双向串口、两路 I2C、以太网、CAN、USB、SD 连续读写/热插拔/掉电恢复、控制输出安全态。
